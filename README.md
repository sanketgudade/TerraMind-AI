# TerraMind-AI
TerraMind AI is an enterprise-grade geospatial artificial intelligence system engineered to ingest, clean, cluster, analyze, and classify active wildfire detections across the Indian subcontinent (Lat: 6°N–38°N, Lon: 65°E–100°E). Operating on over **1.065 Million** satellite observations from NASA FIRMS (VIIRS sensor aboard Suomi-NPP).
